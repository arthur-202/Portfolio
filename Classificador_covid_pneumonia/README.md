# Classificador de Pneumonia e Covid-19

*Esse projeto tem o intuito de demonstrar uma alternativa de classificação de covid-19 e pneumonia.*
**Considerações:**
- No próprio notebook tem as instalações necessárias, como base de dados.
- Para ter acesso ao dataset usado para o treinamento basta acessar o kaggle: "https://www.kaggle.com/datasets/paultimothymooney/chest-xray-pneumonia"
- Usei o modelo ResNet50 pré-treinado para o desenvolvimento desse classificador
